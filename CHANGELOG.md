# Changelog

## 0.1.0 — 2026-10-26

- First release: encoding and mojibake detection, delimiter sniffing, title/footer removal,
  locale-aware numbers (per-column decimal detection), dates, booleans and null tokens.
- `Table` with `records()`, `to_csv()`, `to_json()`, `to_pandas()` and a detection report.
- `tidyread` command-line tool.
